계정과 데이터 삭제 요청

앱을 사용할 수 있다면 앱 안에서 바로 삭제할 수 있습니다. 앱에 접근하기 어렵다면 이메일로 삭제를 요청해 주세요.

앱에서 직접 삭제

  1. 와따가따에서 설정 → 계정 관리로 이동합니다.
  2. 계정 삭제를 선택하고 안내에 따라 본인 확인을 완료합니다.
  3. 앱 데이터와 Firebase Authentication 계정이 모두 삭제된 뒤 완료 화면이 표시됩니다.

계정은 유지하고 기록과 설정만 지우려면 설정 → 데이터 → 전체 데이터 삭제를 이용하세요.

웹에서 삭제 요청

아래 버튼을 누르면 삭제 요청에 필요한 항목이 포함된 이메일이 열립니다. 계정에 연결한 이메일 주소로 보내주시면 본인 확인 후 계정과 관련 데이터를 삭제합니다.

삭제 요청 이메일 보내기

비밀번호, 로그인 인증코드, Apple·Google 토큰은 보내지 마세요. 익명 계정처럼 이메일이 연결되지 않은 경우에는 사용 중인 기기에서 앱 내 삭제를 이용하는 것이 가장 빠르고 안전합니다.

삭제되는 정보

  • Firebase Authentication 계정과 연결된 로그인 제공자 정보
  • 출퇴근·등하교 기록과 활동 구성
  • 평소 이동 설정, 활동 카테고리, 알림 및 앱 설정

삭제 작업의 안전한 완료와 재시도를 위한 최소한의 처리 상태는 최대 7일 동안 보관된 뒤 삭제될 수 있습니다. 법령상 별도 보관 의무가 있는 경우에는 필요한 정보만 해당 기간 동안 보관합니다.

처리 안내

요청을 받은 뒤 본인 확인에 필요한 내용을 회신할 수 있습니다. 확인이 완료되면 지체 없이 처리하고 결과를 이메일로 안내합니다. 문의는 twowaystudio56@gmail.com으로 보내주세요.
